# AI-Powered Road Accident Prevention System

## Problem
Every year thousands die in road accidents.
Most systems only show past accidents.
Mine PREDICTS future risk zones using AI.

## Solution
Real-time accident risk prediction with
AI-generated safety warnings in plain English.

## Features
-  Live accident heatmap
-  ML risk prediction
-  AI safety warnings (Gemini)
-  Pattern analysis dashboard
-  Automated weekly reports

## Tech Stack
Python | FastAPI | Streamlit | scikit-learn | Gemini AI
